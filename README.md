# The Odin Project (Full Stack Javascript) - Tic Tac Toe

Tic Tac Toe project for the Odin Project Full Stack Javascript course.

Full project specs can be found [here](https://www.theodinproject.com/lessons/node-path-javascript-tic-tac-toe).

---

Features 

- Introduction to IIFE (module pattern) & factory functions, & closure variables.
- Also included a primitive cpu player that picks an available square at random.
